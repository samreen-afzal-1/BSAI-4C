# 📚 Library Assistant Bot

A semantic search chatbot for the university library, built with:
- **MiniLM** (Hugging Face `all-MiniLM-L6-v2`) for sentence embeddings
- **FAISS** for fast vector similarity search
- **Flask** backend with a clean HTML/CSS/JS chat UI
- **Pandas** for CSV preprocessing

---

## Project Structure

```
library_bot/
├── library_data.csv       ← Your dataset (Book_ID, Title, Author, Category, Status …)
├── preprocess.py          ← Step 1: builds QnA pairs, embeds, saves FAISS index
├── app.py                 ← Step 2: Flask server
├── requirements.txt       ← pip dependencies
├── faiss_index.index      ← generated by preprocess.py
├── qna_meta.pkl           ← generated by preprocess.py
└── templates/
    └── index.html         ← Chat UI
```

---

## Setup & Run

### 1 – Install dependencies

```bash
pip install -r requirements.txt
```

### 2 – Preprocess & build the FAISS index

```bash
python preprocess.py
```

This will:
- Read `library_data.csv`
- Generate **QnA pairs** (FAQ + per-book questions)
- Embed every question with **MiniLM**
- Save `faiss_index.index` and `qna_meta.pkl`

> Takes ~1–2 minutes on CPU for 200 books.

### 3 – Start the Flask app

```bash
python app.py
```

Open your browser at → **http://127.0.0.1:5000**

## How It Works

```
User query
    │
    ▼
MiniLM encodes query → 384-dim vector
    │
    ▼
FAISS L2 similarity search → top-3 nearest QnA pairs
    │
    ▼
If distance < 1.5  →  return best answer
Else               →  friendly fallback message
    │
    ▼
Flask /ask endpoint returns JSON → rendered in chat UI
```
